# Brand assets (mobile)

Drop the real logo files here using these exact names. The Expo app (Phase 1) references them by path:

| File              | Used for                              |
| ----------------- | ------------------------------------- |
| `logo.png`        | Welcome screen (horizontal, @3x)      |
| `logo-mark.png`   | App icon source, tab bar, headers     |
| `splash.png`      | Splash screen (centered mark on navy) |
| `adaptive-icon.png` | Android adaptive icon foreground    |

Until these exist the app renders an in-code placeholder with the same proportions.
